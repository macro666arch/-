# 演示视频脚本

> 目标时长：3 分 30 秒左右  
> 主线：从校园痛点出发，把可信答案接成能协作、能完成、能倒计时的办事流程。

## 录制前准备

```powershell
cd 前端-cuc-site
npm run build
npm run start
```

打开 <http://localhost:3000>。当前 `.env.local` 使用本地确定性数据，不依赖后端。录制前清空旧任务：

```js
localStorage.removeItem("cuc-campus-tasks-v1");
localStorage.removeItem("cuc-material-profile-v1");
location.reload();
```

准备两个标签页：

- 标签 1：`http://localhost:3000`
- 标签 2：`http://localhost:3000/test`

## 分镜与逐字稿

### 00:00-00:20 开场：今天要办什么

**画面**：首页工作台。

**念：**

> 校园信息产品的常见问题是“答得很像，但办不成”。我们的起点不是再做一段聊天，而是回答：学生今天到底要办什么，下一步去哪里？

**操作**：鼠标划过问题入口、任务概览和近期节点。

### 00:20-00:45 调研证据与问题定义

**画面**：下滑到“9 份问卷，解决了什么”。

**念：**

> 我们对问卷结果做了哈希去重：三份文件内容相同，最终只有 9 份大一答卷。样本不大，所以我们不把它包装成全校调查。
>
> 但它暴露了明确方向：流程不清、部门不清、链接失效、审批慢、材料不清。我们据此做逐项闭环，也公开列出目前解决不了的部分。

**操作**：点击“查看逐项闭环”，停留两秒，再返回首页。

### 00:45-01:20 补办学生证：多轮追问与个性化材料

**画面**：首页点击“补办学生证需要什么材料？”进入问答。

**操作**：回答出现后继续输入 `那要带什么材料？`。

**念：**

> 第二问省略了“补办学生证”，系统仍能沿用它作为当前主题检索。
>
> 材料不是固定列表。我们在首页选择“本科生、遗失补办、委托他人、现场提交”，办事卡会把官网明确项、系统整理项和待核实项分开。

**操作**：打开办事卡中的材料清单，点击“复制清单”，展示三类来源计数。

### 01:20-01:55 截止日期雷达：区分已知与未知

**画面**：顶部进入“截止雷达”。

**念：**

> 官网写了日期，系统才计算倒计时；没写日期、只写“另行通知”的事项进入待核实区，不会生成假倒计时。
>
> 未来节点可以加入本机任务，也可以导出带提前 24 小时提醒的日历文件。

**操作**：展开一条官方节点，点击“加入任务”；再展示历史区和待核实区。

### 01:55-02:35 任务协作：从知道到完成

**画面**：进入“我的任务”。

**操作**：展开刚加入的任务，勾选一项步骤和一项材料，把负责人改为“甲”，填写一句交接说明。

**念：**

> 任务保存在当前浏览器，刷新后仍然存在。任务可以分配给甲乙丙丁，记录协作人和交接说明，也能分别勾选步骤与材料。
>
> 这里解决的是小组执行与学生自查，不冒充学校审批系统，也不声称跨设备同步。

**操作**：刷新页面，确认勾选和任务仍在。

### 02:35-03:05 信息冲突与边界

**画面**：进入智能问答，输入 `学籍管理科的电话是多少？`。

**念：**

> 校园资料经常出现多个官方说法。系统不随机选一个，而是并列展示号码、来源和差异。答不出来时也会明确拒答，并给具体核实渠道。

**操作**：展示冲突来源，再问“那电话呢？”观察上下文接续。

### 03:05-03:30 现场验收

**画面**：进入 `/test`，点击“重新跑一遍”。

**念：**

> 这页不是写死的漂亮报告。它和命令行共用 56 道题及判定规则，现场执行。
>
> 当前结果是 56 道通过：33 道有依据、2 道冲突、21 道无法确认。拒答比例高不是失败，而是我们没有替官网猜答案。

### 03:30-03:40 收尾

**画面**：返回首页，停在问卷闭环和边界提示。

**念：**

> 我们真正补上的不是“更多功能”，而是四件事：追问能接上、材料能因人而异、截止能变成行动、数据缺口能被看见。
>
> 谢谢。

## 常见问题

| 现象 | 处理 |
|---|---|
| 首页能开但点击报模块错误 | 停止旧开发服务，执行 `npm run dev`，不要与 `npm run build` 并行 |
| 问答提示后端失败 | 确认 `.env.local` 为 `NEXT_PUBLIC_USE_MOCK=true` 后重启服务 |
| 任务列表为空 | 先在办事卡或截止雷达点击“加入任务” |
| 日历下载失败 | 只有含明确日期的任务才能导出 `.ics` |
| `/test` 不是 56/56 | 执行 `node scripts/test56.mjs` 查看失败题目 |
